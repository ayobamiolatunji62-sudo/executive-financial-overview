Executive Financial Overview Dashboard

Project Overview

This project involves the development of an interactive Executive Financial Overview Dashboard using Microsoft Power BI.

The dashboard provides a structured view of financial performance, enabling management to monitor key financial indicators, identify performance trends, and support informed business decisions.

Project Objectives

- Analyse total revenue and operating expenses.
- Monitor operating profit and profit before tax (PBT).
- Evaluate year-over-year (YoY) financial performance.
- Identify departmental cost contributions.
- Track key financial performance indicators.

Tools and Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel

Key Areas of Analysis

- Revenue performance
- Operating expenditure analysis
- Profitability analysis
- Year-over-year comparisons
- Departmental cost analysis
- Financial performance indicators

Project Deliverables

- Interactive financial dashboard
- Executive financial performance overview
- Management insights and recommendations

Skills Demonstrated

- Data analysis
- Data visualisation
- Financial reporting
- DAX calculations
- Business intelligence
- Analytical storytelling

Project Purpose

To transform financial data into meaningful insights that support performance monitoring, financial evaluation, and management decision-making.
